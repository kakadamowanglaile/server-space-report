# 报告格式与退出状态

结构化报告为 UTF-8 JSON，第一版 `报告格式版本` 为 `1`，主要字段采用中文。未知数值用 `null` 或不提供该字段，禁止填零冒充已测量。

## 顶层字段

`报告格式版本`、`工具版本`、`开始时间`、`结束时间`、`用时秒`、`目标目录`、`系统`、`深度扫描`、`单项超时秒`、`检查结果`、`已取消`。

时间采用带时区的标准时间文字。系统只含类型、内核和架构，不含机器名称、IP 地址或账号。每次检查分项由 `项目`、`状态`、`范围`、`数据`、`说明` 组成。不同项目的 `数据` 随采集种类变化，调用者应先检查状态和字段存在性。

## 检查状态

- 完成：在说明中的支持范围内完成此次检查，不代表覆盖所有存储机制。
- 部分完成：保留部分数据，但存在权限、格式或对象变化等限制。
- 权限不足、工具缺失、超时、失败：不能据此得出“没有占用”。
- 未启用：例如没有指定 `--deep`，没有做目录扫描。
- 不适用：功能不适用于当前环境或明确排除的类型。

字节数、文件数、计数器是整数。带“估算”或“近似”标记的数据来自上游格式化值，不能反推为精确测量。文件列表不是可删清单。终端显示会转义控制字符，JSON 使用标准字符串转义，不改变原始名称语义。

## 退出码

| 数值 | 含义 |
|---|---|
| 0 | 检查完成，或只有明确未启用/不适用项 |
| 1 | 至少一项检查不完整、权限不足、缺工具、超时或失败；报告仍可使用 |
| 2 | 参数或平台不受支持，或者报告保存失败 |
| 130 | 使用者取消；只能把结果视为部分报告 |
| 141 | 输出管道的接收端已经关闭；停止输出，不继续宣称报告完整 |

运行进度写入标准错误，报告写入标准输出。自动化使用者应读取保存的 JSON，而非解析供人阅读的终端对齐格式。
